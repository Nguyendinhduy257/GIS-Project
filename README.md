# Chọn vị trí trạm sạc xe điện bằng GIS (Nam và Bắc Từ Liêm)

```
tram_sac_xe_dien/
├─ tram_sac_xe_dien.ipynb   # toàn bộ phần làm, chạy từ trên xuống
├─ du_lieu/                 # dữ liệu tải về và dữ liệu trung gian
├─ ket_qua/                 # bản đồ, top 10, biểu đồ (tự sinh)
├─ bao_cao/khung_bao_cao.md
└─ environment.yml
```

## Chạy

1. Anaconda Navigator, Environments, Import, chọn `environment.yml` (hoặc `conda env create -f environment.yml`).
2. Launch Jupyter từ môi trường `evgis`, mở thư mục dự án và mở `tram_sac_xe_dien.ipynb`.
3. Chạy từng ô từ trên xuống. Phần 3 cần tải thủ công file WorldPop vào `du_lieu/`.
